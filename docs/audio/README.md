# 鲸鱼娘说话拟声

当前采用用户试听后选定的 **light-girl-v5**：在尖细版上微降约两个半音，以明亮、轻盈的电子感为方向。基础频率 930 Hz，共振峰倍率 1.6，削弱基频厚度；开心、思考、得意、惊讶和抱歉只作小幅音高、节奏与音量变化。全部为原创合成波形，无游戏采样、角色录音或外部音源。

试听：[当前 6 秒 WAV](whale-speech-preview-v5.wav)。`whale-speech-preview.wav` 是同内容的固定别名，v2–v4 留作本轮试听比较。浏览器中的声音直接由 TypeScript DSP 合成，不下载 WAV 文件。

运行 `node scripts/build-speech-preview.mjs` 可用与游戏相同的 DSP、音量和节奏重建当前试听及 [数值报告](preview-report.json)。文件为 48 kHz 单声道 16-bit PCM，包含开心、思考、抱歉三段台词的拟声；6 秒内 17 个短音，无削波，最短间距 100 毫秒。

游戏每显示两个新字符尝试触发一个 60–80 毫秒短元音，频率上限每秒 12 个。空白和标点无声，句尾留出停顿，同一元音不连续重复；系统处理提示不触发拟声，Agent 的过程对白正常发声。全角括号内的动作静音，跨分片也保持。没有音频待播队列，跳过文字、开始新消息、静音、页面隐藏及卸载时取消当前声音。

首次声音默认开启，入店按键或点按解锁共享 AudioContext。`mgo.sound.v1` 只保存当前标签页的声音开关；刷新遇到浏览器自动播放限制时，首次交互解锁，只播放之后显示的新字。音频不可用不会影响聊天或点单。
