# 情绪与等待表情

Agent 可选择原有六种情绪及 `shy`、`eager`、`pout`、`sleepy`。害羞用于被夸，期待用于美食话题，鼓腮用于友好的小玩笑，困困用于轻松闲聊；提示词要求在核价、订单异常或客人着急时保持认真。四个新情绪使用现有 neutral 拟声参数，`light-girl-v5` 音色与动作静音规则不变。

新增思考图片只属于前端 `CharacterVisual`，不进入 Agent 枚举。SSE 和订单结构没有增加字段，旧六种表情与已保存会话继续有效。新客户端遇到未知情绪时回退到 neutral。

## 显示规则

优先级为：错误 → 递单 → 正在生成/播放的对白 → 等待空档 → 普通待机。等待条件是当前轮仍在处理、没有未完成台词、已收到的文字全部显示完，且最终回复尚未开始。网络分片之间的短暂停顿不会误触发等待脸。

等待时在原思考、认真查单、侧目回想之间随机选择，每隔 4–7 秒变化，避免连续重复；随机间隔 3–5 秒闭眼约 120 毫秒，恢复当前思考脸。仅改变画面，不改变对白情绪或音频参数，也不发送聊天、模型或 MCP 请求。

新台词、最终回复、错误、递单、新一轮、页面隐藏及卸载都会取消旧计时器。返回页面重新计时，不补播过期变化。减少动态效果时使用原有静态思考脸，停用轮换和眨眼。

## 资源加载

原有入店预加载列表保持。新图在柜台空闲时后台逐个下载、解码；忙碌、说话或隐藏时停止启动下一张后台任务。需要显示的图片可单独按需加载，聊天和文字显示不等待它完成。图片未解码或失败时使用已就绪的旧表情，直到新图可以显示；失败资源在当前页面不反复重试。

v2/v3 路径采用长期不可变缓存，切脸时复用资源。素材修订须递增目录或文件名。原始素材、提示词、PNG 审计及 WebP 清单见 [素材说明](../art/ASSETS.md)。

## 验证入口

`npm test` 覆盖优先级、计时取消与重启、随机选择不重复、120 毫秒眨眼、减少动态效果、只选已加载图片、加载失败回退、新枚举流式校验和未知值回退。

可用受控 SSE 夹具检查长等待，无需凭据、不会调用真实服务：

```bash
node scripts/serve-character-fixture.mjs
```

默认从本地 `http://127.0.0.1:3119` 读取页面及图片，可通过 `MGO_FIXTURE_UPSTREAM` 修改。打开 `http://127.0.0.1:3131`，输入 `表情:shy`、`表情:eager`、`表情:pout`、`表情:sleepy`、`等待演示`、`递单演示` 或 `错误演示`。3132 端口将新图固定返回 503，用于回退测试。夹具不转发聊天或写请求；`/fixture-stats` 仅返回测试计数。完成后停止脚本即可。
